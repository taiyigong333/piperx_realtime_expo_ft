# 文档导航与维护规则

更新：2026-11-02（Asia/Shanghai）。

## 从哪里开始

1. 新会话先读根目录 [HANDOFF.md](../HANDOFF.md)，再读[项目交接](项目交接.md)。
2. 日常使用 GUI 读[浏览器客户端使用说明](浏览器客户端使用说明.md)，命令行首次启动读[真机强化学习快速开始](真机强化学习快速开始.md)。
3. 开展实验先读[实验计划](实验计划.md)；数据和模型关系读[架构与数据约定](架构与数据约定.md)、[完整训练流程](Real-Time-EXPO-FT完整训练流程.md)。

## 后续整理规则

- 当前操作与约定留在根目录的对应主题中，不按日期复制多份常用说明。
- 新实验、部署验收、问题排查和设计复盘写入历史对应类别，文件名前加实际记录日期；根目录仅更新结论和链接。
- 原始日志、数据、权重、运行截图与现场私有配置仍保存在被忽略目录，不归入Git文档。
- 迁移文档时同步修改 Markdown 链接与行内路径，检查本地链接和历史正文完整性。
- 软件测试、GPU小算子、完整模型训练、真实机器人评估分别记录，不能互相替代。
