## 逐层表示合同

| 层 | 本工程表示 | 约束/变换 |
| --- | --- | --- |
| 机器人观测/离线state | 基坐标系绝对法兰XYZ(m)+RPY(rad)+夹爪实测宽度(m)，7维 | 零工具偏移；不是六关节角；原state统计保持不变 |
| 原离线action | 下一帧反馈state，末帧重复 | 保留data-transfer原语义，是目标代理，不是原始遥操命令 |
| 在线action/归档 | 实际下发的7维绝对法兰目标和夹爪宽度 | 反馈另存；不以到达状态替换实际目标 |
| replay/critic/edit | 同一套绝对动作，按绝对action统计归一化 | edit是在归一化绝对动作上的残差；这不是控制器delta或速度 |
| VLA训练和采样内部 | 前六维相对chunk参考观测的delta，夹爪绝对宽度 | 使用原checkpoint的VLA delta统计；整块共用同一参考观测，不能逐帧差分 |
| RTC缓存/前缀 | 缓存归一化绝对动作，包括实际选中并编辑的前缀 | 送入下一次VLA前，按新参考state重新转delta；输出再还原绝对动作 |
| 模型张量 | 7维有效量，按上游补齐至32维 | 补零不是新增关节；右腕有效，左腕掩码False |
| 硬件策略执行 | `move_p`六维绝对法兰位姿＋`move_gripper_m`绝对宽度 | 安全检查拒绝越界，不静默裁剪，不二次积分delta |
| episode固定归位 | 6维关节绝对角(rad)，`move_j`固件规划 | 独立于策略动作，不写入rollout/replay |

绝对到VLA的核心变换为：同一chunk中所有$k$，$\Delta a_{t+k,0:6}=a_{t+k,0:6}-s_{t,0:6}$，夹爪维度不减state；输出反向相加。这是沿用原训练转换，不引入SE(3)对数映射、角度折回或其他新表示。

Dynamic Picking配置显式设置`edit_action_xyzg: true`；省略该字段也默认true，按论文只屏蔽edit的旋转增量。设置`false`可选择全7维编辑，两种模式均保留；基础VLA始终预测完整RPY。该设置影响后续在线RL，已有RTC-SFT权重不因此重训；不同模式使用独立RL run/checkpoint目录，避免混淆实验。当前H=30（论文16）、replan=8、delay=5（论文动态抓取3）、RL batch=4（论文64）、候选8/8（论文32/32）、更新间隔30（论文动态抓取25），均属于本机适配差异；delay仍须按实测推理延迟决定，不能从其他任务照抄。固定起始关节也按用户要求执行，不声称复现论文初始状态随机化。

## 固定归位流程

来源只用于复位：piperx `/home/cv/gcj/project/baseline_fast/openpi/configs/safety.yaml`的home及`piper_openpi/controller.py::_home`。本地配置为`configs/client/home.openpi.yaml`，目标j1..j6：

```text
[0.0111352006, 0.8443379322, -1.0155198253, 1.1606788592, 0.0746477321, 0.0196698607] rad
```

CLI的READY或GUI“现场就绪，归位并开始”确认后：检查实时反馈、相机、控制器状态、起点关节及工作空间、目标FK及距离→使能→确认CAN/J模式→10%速度`move_j`→读取下发后的关节反馈，最大逐关节误差≤0.035rad才通过→确认P模式恢复→返回下一条初始观测。30秒未到位、反馈过期或其他异常会急停锁定，不继续rollout。停止事件能中断归位等待，GUI归位期间也保留失联保护。

物体/方块复位仍由现场操作；不自动打开夹爪，不推测安全放物位置。关节目标一致不能证明环境、负载及桌面障碍允许整条路径。现场仍需原采集预检、归位路径验收及短回合闭环验证。
