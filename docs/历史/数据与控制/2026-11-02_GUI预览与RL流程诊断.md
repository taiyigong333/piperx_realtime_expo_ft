## 执行设计

1. 预览：独立20Hz刷新，每路一个在途请求；回放、面板隐藏和页面隐藏暂停；保持600ms心跳和控制频率不变。
2. RL：核实RTC延迟路径首次编译；在运动前预热首次和延迟重规划两条路径，测量预热后延迟；看门狗保留0.5s，不用扩大阈值掩盖问题。
3. 可观测性：保留停止根因，区分服务器加载、连接、预热、等待人工归位、采集、复核、更新和保存；远端已退出时不无限等连接。
4. 流程：整理详细操作与状态合同，提供明确当前步骤/下一步；人工确认后才允许归位和策略，普通结束回合与急停用途清楚。
5. 验证：前端调度测试、软件RPC/回归、必要GPU只读推理；默认不重放真实机器人动作。每阶段提交推送，双机同步并保留现场配置。
